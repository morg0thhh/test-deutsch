# Входное тестирование на первом пробном занятии (немецкий)

Собрано 2026-09-30. Задача: понять, какие бывают форматы оценки стартового уровня ученика.

---

## 1. Пять базовых типов инструментов

Классификация Center for Applied Linguistics (CAL) — стандартная рамка для placement-тестирования.

| Тип | Как работает | Плюсы | Минусы |
|---|---|---|---|
| **Multiple-choice (грамматика/лексика)** | Закрытые вопросы на выбор формы | Легко админить и автоматически считать | Меряет знание *о* языке, а не умение общаться |
| **Performance-based задания** | Реальные коммуникативные ситуации (написать письмо, разыграть диалог) | Показывает, что ученик реально может | Дорого разрабатывать, проверять вручную |
| **Устное интервью (OPI)** | Беседа с преподавателем, формальная или неформальная | Прямая оценка говорения + сбор контекста | Долго, требует квалификации оценщика |
| **Самооценка / анкета** | Ученик сам отмечает Can-Do и рассказывает опыт | Очень дёшево, даёт мотивацию и цели, вовлекает | В одиночку ненадёжно, зависит от честности |
| **Shortcut-тесты (C-Test, elicited imitation)** | Короткие «быстрые» замеры общей компетенции | Быстро, хорошо шкалируется, есть исследования | Свой собственный сделать — нужна методическая экспертиза |

Вывод из источника: ни один тип не используется в одиночку — рабочая схема это **анкета + быстрый объективный замер + короткая устная часть**.

---

## 2. C-Test — «золотой стандарт» быстрой оценки

**onSET** (Goethe-Institut / g.a.s.t., используется вузами Германии) — самый известный пример.

Устройство:
- 8 коротких текстов, в каждом **20 пропусков**
- первое и последнее предложение текста — целые (дают контекст)
- в середине у **каждого второго слова удалена вторая половина**, её надо дописать в правильной форме
- **5 минут на текст**, максимум ~40 минут на весь тест
- результат — уровень по CEFR: A1 / A2 / B1 / B2 / C1+

Почему это работает: заполнение половинок слов задействует одновременно лексику, грамматику, орфографию и понимание связного текста — то есть коррелирует с общей языковой компетенцией лучше, чем отдельный грамматический тест такой же длины.

Ограничение для нас: **C-Test не работает на A0/A1-старте** — нулевому ученику нечего дописывать. Для пробного занятия с нуля нужен другой вход.

## 3. Адаптивный MCQ — то, что делают языковые школы

Массовый формат коммерческих школ. Пример — DeutschAkademie:

- **адаптивный**: сложность следующего вопроса подстраивается под ответы, вопросов задаётся ровно столько, сколько нужно
- **15–20 минут**
- типы заданий в миксе: верно/неверно, выбор грамматической формы, сопоставление предложений, заполнение пропусков, аудирование (верно/неверно), множественный выбор, сортировка элементов, оценка корректности предложения
- на выходе: уровень A1–C2, детальная расшифровка, рекомендация курса, результат на почту

Разброс по рынку: от **3 минут** (sprachenlernen24, чисто словарный запас) до **20–30 минут** (Sprachschule Aktiv). Большинство — без регистрации, без сертификата.

Ключевой приём адаптивности: стартовать с середины (A2/B1), при двух ошибках подряд — вниз, при двух верных — вверх. Это экономит ~60% вопросов против линейного теста.

## 4. Сам пробный урок: как он устроен на практике

Общая рекомендация рынка — **не «урок», а «консультация/диагностика», 30–40 минут**.

Структура (обобщено из методичек для репетиторов):

1. **Разогрев, 5–10 мин** — снять стресс (первый урок почти всегда стресс). Question Wheel, «две правды и ложь», emoji check-in.
2. **Цели и бэкграунд, 10–15 мин** — зачем язык, какие навыки важны, что учил раньше. Идёт по заранее заготовленной анкете.
3. **Практика/диагностика, 15–20 мин** — показать метод на посильном материале. Тестирование держать в пределах 15–20 минут, иначе ученик заскучает.
4. **Обратная связь, 5–10 мин** — сначала сильные стороны, потом зоны роста. Плюс мини-опрос из 3–5 вопросов про комфорт и предпочтения.
5. **Программа и цена, 5–10 мин**.
6. **Логистика, 5 мин**.

Важные детали:
- часть консультации ведётся **на изучаемом языке** — это сразу даёт замер аудирования и говорения, без отдельного теста
- если уровень минимальный — говорение всё равно включать, но с опорами
- письменный тест сам по себе меряет только грамматику и словарь; для точного уровня нужна живая часть

## 5. Готовая рамка для самооценки

**CEFR Self-Assessment Grid (Europass)** — официальная таблица дескрипторов по 5 навыкам (Hören, Lesen, An Gesprächen teilnehmen, Zusammenhängendes Sprechen, Schreiben) × 6 уровней (A1–C2). Есть немецкая версия.

Практическое применение: ученик отмечает «могу/не могу», это занимает 2–3 минуты и даёт стартовую гипотезу об уровне ещё до теста → можно с неё начать адаптивную ветку.

---

## 6. Что из этого складывается в рабочую схему

Для пробного занятия разумный гибрид, ~25–30 минут:

1. **Анкета целей + Can-Do самооценка** (3–5 мин, до урока, асинхронно) → гипотеза уровня
2. **Адаптивный блок с MCQ + пропуски** (10–15 мин) → объективный замер грамматики/лексики, старт от гипотезы
3. **Мини C-Test** (5 мин, один текст) — только если самооценка ≥ A2 → уточнение общей компетенции
4. **Устная часть в разговоре с преподавателем** (5–10 мин) → говорение/аудирование, оценивается по дескрипторам, а не баллами
5. **Выдача**: уровень по CEFR + расшифровка по навыкам + рекомендация программы

Отдельная ветка для **A0**: если самооценка «с нуля» — тест заменяется на пару заданий-зондов (узнаёт ли латиницу/знакомые интернационализмы, был ли другой иностранный) и всё остальное время уходит в живой урок.
