# Einstufungstest Deutsch 🐱

Интерактивный входной тест по немецкому для пробного занятия. Поднимается одним
контейнером, ссылку можно отдать ученице.

## Запуск

```bash
docker compose up --build
```

Дальше → http://localhost:8000

База (`app/data/test.db`) лежит в примонтированном томе, так что профили и
результаты переживают пересборку.

## Что внутри

**Главная (`/`)** — профиль и рейтинг.
Ученица вводит имя, выбирает котоаву из 20 картинок, жмёт «Начать тест».
Ниже — рейтинг: кто на каком этапе прямо сейчас, с прогресс-баром;
обновляется сам раз в 8 секунд.

**Тест (`/test`)** — 21 задание, по одному на экран.

| Часть | Заданий | Что внутри |
|---|---|---|
| 🎧 Hören | 6 | видео с YouTube, встроенные прямо в страницу |
| 📖 Lesen | 4 | объявление, письмо, статья, аналитический текст |
| 🧩 Grammatik & Wortschatz | 9 | от спряжения до пассива с модальным |
| ✍️ Schreiben | 2 | открытые ответы, проверяет преподаватель |

Механика:
- выбрала вариант → через 0,38 с само переносит на следующий вопрос
- «← Назад» и ряд кружков-номеров сверху — можно вернуться к любому вопросу,
  отвеченные подсвечены
- ответы пишутся в sessionStorage и на сервер, страницу можно закрыть и вернуться
- на финише, если что-то пропущено, предложит доответить

**Аудирование.** Ролики встроены через `youtube-nocookie.com` и уже перемотаны
на нужную секунду — ничего искать не надо. Рядом ссылка «открыть на YouTube»,
если встраивание где-то заблокируют.

**Разбор для преподавателя (`/lehrer/<id>`)** — все ответы с пометкой верно/неверно,
правильные варианты, статистика по уровням и письменная часть целиком.
`id` виден в `/api/players`.

## Как считается уровень

Каждое задание помечено уровнем (A1/A2/B1/B2). Уровень = самый высокий, на котором
**и на всех уровнях ниже** набрано ≥ 60 %. Логика «не проскочить»: если B2 угадан,
а A1 провален, результат останется A0. Проверено тестами — см. ниже.

Schreiben в балл не идёт: автоматически такое не оценить, это к преподавателю.

## Безопасность и мелочи

- Ключи к ответам живут только на сервере, в `/api/config` их нет — подсмотреть
  в исходнике страницы не получится
- У профиля есть токен, чужие результаты не перезаписать
- Имена выводятся через `textContent`, без `innerHTML`
- Тёмная тема, мобильная вёрстка, клавиатурная навигация, `prefers-reduced-motion`

## Структура

```
app/
  backend/
    app.py        API, SQLite, отдача страниц
    content.py    задания + ключи + логика уровня   ← править контент здесь
  static/
    index.html    профиль + рейтинг
    test.html     тест и экран результата
    teacher.html  разбор
    style.css
    cats/         20 котиков
  data/           база (создаётся сама)
Dockerfile
docker-compose.yml
```

Добавить вопрос — дописать словарь в `QUESTIONS` в `content.py`,
фронт подхватит сам, ничего больше менять не надо.
